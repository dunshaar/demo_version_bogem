# Богема — локальная версия с формами на обеих страницах

Последние прямые правки владельца от 11 октября 2026 имеют приоритет над
противоречащими пунктами ТЗ v5. Главная представляет группу и принимает обращение,
репертуар показывает все песни и принимает музыкальные пожелания.

## Запуск

Без установки зависимостей и сборки:

```sh
python3 "/Users/daniils./Desktop/Богема/Сайт/preview_server.py" 8786
```

Открывать в Google Chrome: http://127.0.0.1:8786/ и http://127.0.0.1:8786/repertoire/.
Сервер локальный, поддерживает Range для MP4. file:// не подходит для модулей/JSON.

## Формы и данные

- Обе формы: обязательные имя и телефон; способ связи и дата необязательны.
- Контактный способ: без предпочтения, звонок или Telegram. Отдельные реквизиты
  мессенджеров и дополнительные поля не запрашиваются.
- Согласие не отмечено заранее, обязательно для демонстрационной отправки.
  Сейчас это визуальный элемент согласованного прототипа; настоящий документ
  и фиксацию его версии нужно подключить перед реальной обработкой данных.
- Главная прикрепляет изменения песен только по явному выбору.
- Репертуар отправляет текущие «Хочу / Не надо» обеих программ; без изменений
  предлагает сначала отметить песни. Недоступные записи исключаются только
  после подтверждения пользователя.
- `forms-config.json`: mode=demo, enabled=false, адреса доставки=null.
  Подтверждение на экране не означает доставку: внешнего запроса нет.
- Контактные поля, способ связи и согласие не сохраняются в localStorage/URL.
  После демоуспеха очищаются; песенные пожелания сохраняются.
- `request-contract.mjs`: схема 3, включая preferredChannel и consent.
  Проверки будущего адаптера с подменой ответов не доказывают реальную доставку.
- `preferences-store.mjs`: схема хранилища 5, только want/skip; исходное «Можно»
  не занимает запись. Миграция схемы 3 сохраняет стабильные ID.
- `repertoire/data.json`: 210 песен группы и 151 трио, порядок/ID сохранены.
- `project-data.mjs`: реальные составы, контакты и фотографии. Просмотр
  состава не выбирает услугу и не добавляет скрытых полей в заявку.

## Интерфейс

Кнопка заявки в правой части шапки, в hero кнопки нет. «О группе» содержит
три live-записи, включая сольный «Летний дождь». Пять составов переключаются
мышью и клавиатурой; на телефоне раскрытие рядом с выбранной строкой.

Видимые тексты интерфейса без конечных точек и длинных тире. Названия песен,
контакты, пути и реальные материалы не нормализуются под это правило.
