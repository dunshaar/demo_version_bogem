# Богема — локальная визуальная доработка по ТЗ 4.0

Статичный сайт: главная `index.html`, каталог `repertoire/index.html`. Тёмная тема,
реальные материалы группы, светлый тизер и отдельная страница репертуара.

## Запуск

Без установки зависимостей и сборки. Локальный сервер с поддержкой перемотки MP4:

```sh
python3 "/Users/daniils./Desktop/Богема/Сайт/preview_server.py" 8786
```

Открыть в Google Chrome: http://127.0.0.1:8786/ и http://127.0.0.1:8786/repertoire/.
Сервер слушает только локальный компьютер. `file://` не подходит для ES-модулей,
загрузки JSON и стабильного localStorage.

## Данные и обращение

- `repertoire/data.json` — источник обоих каталогов; 210 песен группы и 151 трио.
- `project-data.mjs` — подтверждённые коммерческие предложения и контакты.
- `preferences-store.mjs` — функциональные музыкальные отметки и выбранный состав.
- `request-contract.mjs` — схема и ограничения запроса, снимки и разбор результата.
- `forms-config.json` — доставка выключена. Форма позволяет подготовить обращение
  и самостоятельно связаться с группой; это не отправка и не бронирование.
- Просмотр фотографии состава не выбирает услугу. Выбор для обращения
  выполняется отдельным действием; программа каталога от него не зависит.
- Персональные поля не сохраняются в localStorage/URL. Музыкальная подборка
  прикрепляется только явно, не автоматически после восстановления.

Сервер обработки, разрешённый тестовый получатель и согласованные документы
оператора отсутствуют. Сетевые состояния проверяются подменой ответов в тестах;
это не доказательство реальной доставки. Включать интеграцию можно только после
серверной проверки схемы, идемпотентности, лимитов и контроля неизвестного результата.
Не обещается отсутствие дублей при потерянном ответе внешнего сервиса.

## Проверки и рабочие материалы

ТЗ, снимки до/после, генератор полного HTML каталога, тесты и отчёт находятся в
`../Доработка v4 2026-10-11/`. Предыдущие контракты, генератор каталога и
проверки v3 — в `../Доработка 2026-10-11/`. Рабочие исходники клиента
и эти артефакты не публикуются.
После изменения каталога обновлять полный HTML генератором `build-repertoire.mjs`
из папки v3 и проверять совпадение ID; не редактировать две независимые базы.
Существующие проверки плеера/Range находятся в `../tests/`.

## Публикация

Текущая ветка `bogema-local-visual-v4-20261011` предназначена для локальной проверки.
В этой задаче GitHub Pages и соседняя опубликованная V2 не менялись.
Перед будущей публикацией отдельно согласовать версию, адрес и транспорт формы.
Хостинг должен поддерживать HTTP Range для MP4. При смене домена обновить
canonical и OG/Twitter URL обеих страниц; сейчас сохранены прежние адреса demo.
Индексация демо выключена. Секреты, заявки, тесты, отчёты и исходные архивы
не включать в публичный репозиторий; allowlist файлов задан в `.gitignore`.
