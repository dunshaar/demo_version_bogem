# Богема — сайт кавер-группы

Публикация: https://dunshaar.github.io/demo_version_bogem/

Статичный сайт: главная и отдельный репертуар. GitHub Pages использует ветку
`main` и корень репозитория; дополнительная сборка не требуется.

## Содержимое

- Пять вариантов состава и четыре видео группы
- Полный репертуар: 210 песен группы и 151 трио
- Музыкальные пожелания «Хочу / Можно / Не надо» и постоянная сводка текущей программы
- Раздельные отметки группы и трио, сохранение между посещениями
- Главная заявка передаёт только контакты; песни относятся к форме в репертуаре
- Форма обращения на главной и форма пожеланий в репертуаре
- Имя и телефон обязательны, способ связи и дата необязательны

## Демонстрационные формы

`forms-config.json` включает деморежим. Подтверждение появляется локально,
данные никуда не передаются. Контакты и согласие не сохраняются в браузерном
хранилище; сохраняются только музыкальные пожелания.

Реальный обработчик и документы подключаются отдельным этапом.
`request-contract.mjs` описывает схему 3 будущего подключения; секретов в сайте нет.

## Размещение

Все пути относительные и работают в подпапке GitHub Pages. Для локального
просмотра нужен HTTP-сервер. Для перемотки MP4 сервер должен поддерживать Range.
Видео загружаются только после открытия плеера. Уменьшение движения учитывается.

`repertoire/data.json` — источник каталога; при изменении списка нужно согласованно
обновлять статическую разметку и сохранять ID для существующих пожеланий.
Индексация демонстрационного сайта отключена.

Фото и видео — реальные материалы группы. В репозиторий не входят исходные
клиентские архивы, доступы, отчёты и тестовые заявки.

## Дизайн Framer — 13 октября 2026

Дизайн перенесён из проекта Charming Times / BOGEMA:
https://framer.com/projects/Charming-Times--03aKjQZKpblQL3XqB0T3-8R1g5
Framer используется только как дизайн-источник; опубликованный сайт работает
самостоятельно без Framer runtime, аккаунта или внешних шрифтов.

- Manrope и Spectral находятся в `assets/fonts/`, лицензии сохранены рядом
- Главная: крупное название, смещённая фотография, промо, пять составов,
  светлый репертуар, организация выступления и контакты с формой
- Дополнительные live-видео открываются под промо в «Ещё живые выступления»
- Пять составов переключаются вкладками на всех размерах экрана,
  клавиши стрелок/Home/End поддерживаются; старый мобильный аккордеон заменён
- Репертуар светлый, каталог и контракты пожеланий прежние
- Счётчики сопровождают каталог и форму; новые ссылки к форме/наверх
  прокручивают страницу за 450–850 мс с учётом уменьшения движения
- Все фотографии, постеры и четыре видео взяты из настоящих материалов Богемы
