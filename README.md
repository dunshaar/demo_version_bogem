# Богема — демо сайта

Готовый статичный сайт. Главная страница — `index.html` в корне.

## Публикация

- GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.
- На другом статическом хостинге: без команды сборки, папка публикации — корень репозитория.
- Видео MP4 должны отдаваться с поддержкой HTTP Range, чтобы работала перемотка.

Формы работают в демонстрационном режиме без отправки контактов. Сервер доставки,
домен и юридические документы подключаются на финальном этапе. Индексация отключена.

Репозиторий содержит только файлы сайта. Материалы заказчика, ключи, тесты,
отчёты и резервные копии разработки сюда не включены. Для дальнейших обновлений
список публикуемых файлов явно задан в `.gitignore`.

Карточка ссылки настроена для GitHub Pages. При смене домена обновите абсолютные
адреса canonical, og:url и og:image/Twitter в обеих HTML-страницах.

## Редизайн 6 октября 2026

Тёмная версия v3. Все тексты и композиция обновлены; фотографии, видеозаписи,
каталог песен и контакты основаны на материалах группы.

- `styles.css` — локальные шрифты, токены, навигация, диалоги и общая адаптивность.
- `home.css` — композиция главной; `app.js` — меню, видео, выбор состава и анимации.
- `forms.js` / `forms.css` — единая форма и маска телефона.
- `player.js` / `player.css` — управление видео, Space, стрелки и F/А.
- `repertoire/` — самостоятельный каталог группы и трио с независимыми отметками.
- `assets/fonts/` — локальные WOFF2 и лицензии OFL; Google Fonts в браузере не запрашивается.

До нажатия на видео MP4 не загружается. Анимации учитывают reduced motion.
