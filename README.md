# Богема — сайт кавер-группы

Статичный сайт: главная, репертуар и портфолио.

Публикация: https://dunshaar.github.io/demo_version_bogem/
GitHub Pages: ветка main, папка / (root), сборка не нужна.

Страницы используют относительные пути и работают в подпапке GitHub Pages. Видео MP4 загружаются после нажатия; сервер должен поддерживать HTTP Range для перемотки. Для локального просмотра нужен обычный HTTP-сервер.

На сайте прямые ссылки на Telegram, телефон и e-mail. Формы, обработчик заявок, бот, аналитика и платёжные сервисы не подключены. Индексация отключена, пока это демонстрационный сайт.

Фото и видео — материалы группы. Репертуар: 210 песен группы и 151 песня трио. Шрифты Oswald размещены локально; лицензия и источник — в assets/fonts/.

При смене адреса обновить canonical, Open Graph и Twitter Card в трёх HTML-страницах. В репозитории — файлы сайта, без ключей, исходных клиентских архивов и отчётов разработки.
